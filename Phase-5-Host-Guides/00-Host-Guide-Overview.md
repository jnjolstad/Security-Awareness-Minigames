## 1. What this experience is (host mindset)

A 30–60 minute (target **45**) narrative escape room for **3–6 players**. They are the after-hours
Incident Response Team at **NIMBUS Cloud Solutions**, racing a **BLACKFROST** ransomware countdown to
expose an insider and enter a kill-switch code. Eight puzzles + a finale alternate physical clues and an
on-screen "NIMBUS Secure Terminal."

Your job is **game master, not teacher**. Keep the story alive, keep teams moving, and let them *discover*
each lesson. Never lecture mid-game — that's what the debrief is for.

## 3. Roles (if you have help)

- **Game Master (required):** reads the intro, watches the room, delivers hints, controls the clock,
  runs the ending + debrief.
- **Floater (optional, for 6+ players or back-to-back groups):** handles resets, watches the second
  team, repositions props. One person can run everything for a single group.

## 4. Run-of-show (45-minute target)

| Clock | Beat | Host action |
|---|---|---|
| −10 min | Reset & arm | Run reset; confirm terminal at login, countdown **not** started |
| −2 min | Seat & brief | Gather team at reception; read the **intro** (file 01) |
| 0:00 | **Go** | Press **Start Mission** on the login screen; countdown begins at 45:00; step back |
| 0:00–0:10 | Break-in (P1–2) | Watch reception + desk; nudge only if stuck ~3 min |
| 0:10–0:20 | Get in (P3–4) | Point to drawer if MFA stalls; watch the phish report |
| 0:20–0:35 | Investigate (P5–7) | Encourage **sub-teams** (USB / Wi-Fi / logs); guard the twist |
| 0:35–0:43 | AI + console (P8) | Remind "Alex said don't trust the assistant" if needed |
| 0:43–0:45 | Finale | Let them feel the clock; celebrate the win |
| +5 min | Debrief | Run file 04; map puzzles → real life |
| after | Reset | Run file 03 for the next group |

## 5. Golden rules for hinting

1. **Wait ~3 minutes** of genuine stuck-ness before stepping in (less near the end).
2. **Start at the lowest hint** that fits and escalate (file 02). Hints are written in **Alex's voice** —
   stay in character.
3. **Protect the twist (Puzzle 7).** If a team fixates on Riley, don't say "wrong" — ask *"could Riley's
   badge even open that door?"*
4. **Use the anti-frustration valves** rather than letting frustration build: the sealed **MFA recovery
   envelope** (=481509), and in emergencies the host **skip** hotkey **Ctrl+Alt+S**.
5. **Never confirm answers aloud** to the room — let the terminal/lock do the confirming.

---

## 6. Host controls (memorise these)

- **Ctrl+Alt+R** — reset the digital game to the start (clears progress, restarts countdown).
- **Ctrl+Alt+S** — host skip: unlocks all on-screen steps (testing / emergency unstick).
- **Reset between groups** — `Phase-3-Computer-Setup/reset.bat` (closes browser, restores files,
  relaunches) + the physical checklist (file 03).
- **Stuck terminal?** Close & relaunch the browser — a fresh session is a clean reset.

---

## 7. Safety & inclusion (quick reminders)

- Everything is **fictional and harmless** — no real malware, lockouts, or data. Say so if anyone's unsure.
- No physical force is ever needed; if a lock won't open, it's the wrong code, not the wrong strength.
- Offer the **non-UV fallback** for any UV clue, keep text high-contrast, and let teams split tasks so
  everyone contributes. Full notes in `Phase-3-Computer-Setup/00-Computer-Setup-Guide.md` §12.
