# Overshare 2: Live customer scenario

A 10-minute customer-disclosure game set as a live assurance call with customer chat, internal chat and screen-share choices.

The customer is authorised to receive only the approved high-level overview. Players identify nine details needing removal or service-owner approval (including whole-desktop share mode), then answer three follow-up decisions about live sharing, technical follow-up and accidental disclosure.

Six approved details act as decoys. The game does not teach a blanket ban on hostnames, versions or infrastructure information: disclosure depends on entitlement, purpose and company rules.

NSM references support access control (2.6), protection of data/secrets (2.7) and incident handling (4.3). The exercise's specific sharing policy is fictional, not an NSM prohibition. All addresses and credentials are fictional; the token is explicitly non-functional.

The engine shuffles details inside infrastructure nodes, rearranges operations cards and shuffles live chat lines. The shared engine also shuffles chain answers. Regenerate `scripts/build-minigames-key.mjs` in the deployment repository after changes to the catalog, risks or answers.

Adding this game increases the championship denominator to eleven through the existing catalog/server key. Existing scores are preserved; participants can add a score for the new game.
