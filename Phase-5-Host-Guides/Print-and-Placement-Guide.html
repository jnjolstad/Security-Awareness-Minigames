Final checks

Build the Room

  1. Print the complete pack. Confirm 20 pages and that the visitor log is landscape.
  2. Cut the handled props. Prepare desk labels, MFA pieces, Riley props, folder labels, badges, and Alex’s notes.
  3. Prepare the lock chain. Put the desk-drawer key and Alex Note #1 in the lockbox; set combination 2071; close and scramble.
  4. Prepare the locked drawer. Put the authenticator, sealed recovery envelope, and Alex Note #2 inside; lock it.
  5. Prepare the desk puzzle. Place four labelled objects, the false sticky password, and A. Mercer nameplate.
  6. Prepare PROJECT FROST. Label the real USB, load the supplied harmless files, and tape it under the evidence shelf.
  7. Build the walls. Mount reception, passphrase, phishing, network, classification, and awareness posters.
  8. Build the evidence area. File the audit/register, label three folders, arrange Riley evidence and six suspect badges.
  9. Secure the answer-bearing alert. Keep the Cloud Exfiltration Alert at the host station until the correct accusation.
  10. Start the technology. Terminal at login with 45:00 idle; standalone tablet timer ready if used.

Materials still required

  • 4-digit lockbox set to 2071
  • Lockable desk drawer + key
  • Real USB stick
  • Clipboard, pen, 2 binders
  • Green, amber, red folders
  • Four small desk objects
  • Envelope, tape, scissors, mounting putty
  • Optional lanyards / badge holders

Final player-view check

  • No host guide or answer key visible
  • No host instruction bars appear on printed props
  • Cloud alert is not in the room
  • Lockbox and drawer are actually locked
  • All clues can be read in room lighting
  • No real company/customer information is used
