Spot the Phish 🎣

Before you click, check all four:

  1. Sender domain looks almost right? (e.g. nimbuscl0ud.com ≠ nimbuscloud.com)
  2. Urgent threat or deadline pressuring you to act now?
  3. Link doesn’t match the real site, or looks foreign/odd?
  4. Generic greeting like “Dear User” instead of your name?

If any apply → Don’t click. Report it.

Reporting a phish protects everyone — it lets Security pull the message from other inboxes and block the sender.
